# cttr-psp-right-stick-camera
Adds right-stick camera control to on-foot gameplay in Crash Tag Team Racing for PSP. Move with the left stick and look around with the right stick without holding R.

Supports PPSSPP and PS Vita via Adrenaline. The ZIP includes both xdelta patches, installation instructions, and checksums to identify the compatible clean game files.

Requires the USA PSP release (ULUS10044). The ZIP includes clean-file checksums and installation instructions. [Download the v1.0.0 patch ZIP.⁠](https://github.com/unassortednonsense/cttr-psp-right-stick-camera/releases/download/1.0.0/CTTR-PSP-Right-Stick-v1.0.0.zip)
